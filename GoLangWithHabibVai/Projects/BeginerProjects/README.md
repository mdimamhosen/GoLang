# Beginner Go Projects

Welcome to the beginner-level Go projects collection! This directory contains practical projects designed to help you learn Go programming through hands-on experience.

## 🎯 Current Projects

### 1. Calculator
A console-based calculator that performs basic arithmetic operations.
- **Skills**: Basic I/O, functions, switch statements, loops
- **Features**: Addition, subtraction, multiplication, division with user-friendly interface
- **Location**: `Calculator/`

### 2. Number Guessing Game
An interactive guessing game with multiple difficulty levels.
- **Skills**: Random numbers, loops, conditionals, user input validation
- **Features**: Three difficulty levels, attempt tracking, feedback system
- **Location**: `NumberGuessingGame/`

### 3. Rock Paper Scissors Lizard Spock
Extended version of the classic Rock Paper Scissors game.
- **Skills**: String handling, functions, game logic, input validation
- **Features**: Five-choice game, computer AI, winner determination
- **Location**: `RockPaperScissorsLizardSpockGame/`

### 4. Todo List Manager
A command-line task management application.
- **Skills**: Structs, methods, slices, user input validation
- **Features**: Add/complete/delete tasks, progress tracking, statistics
- **Location**: `TodoList/`

### 5. Password Generator
Secure password generator with customizable options.
- **Skills**: Random generation, string manipulation, input validation
- **Features**: Configurable length and character sets, strength analysis
- **Location**: `PasswordGenerator/`

## 🚀 Getting Started

1. Navigate to any project directory
2. Read the project's README.md for specific instructions
3. Run the project: `go run main.go`
4. Follow the on-screen prompts
